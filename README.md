## English

CodeMap is a project in its planning stage that aims to help developers understand a software repository's architecture by showing how files and modules relate to one another.

### Planned features

- **Dependency graph:** visualize relationships between files and modules.
- **Project structure explorer:** browse directories and components in one view.
- **Entry-point discovery:** identify likely application entry points.
- **Coupling analysis:** highlight modules with many relationships or difficult dependency patterns.
- **Architecture report:** generate a readable overview of a project's structure and dependencies.

These are planned goals, not implemented features.

### Planned technology

- **Rust** for code analysis and dependency extraction.
- **TypeScript** for the visualization interface.

The implementation choices may change as the project evolves.

### Status

**Early planning.** This repository currently contains documentation and a license only. No executable code is included yet.

### Initial roadmap

1. Choose the first supported languages and project formats.
2. Design a data model for files, modules, and dependencies.
3. Build an initial repository-structure analyzer.
4. Display dependencies in a navigable interface.
5. Add coupling metrics and architecture reports.

## Español

CodeMap es un proyecto en fase de planificación cuyo objetivo es ayudar a los desarrolladores a comprender la arquitectura de un repositorio de software mostrando las relaciones entre archivos y módulos.

### Funcionalidades previstas

- **Grafo de dependencias:** visualizar las relaciones entre archivos y módulos.
- **Explorador de estructura:** recorrer directorios y componentes desde una vista unificada.
- **Detección de puntos de entrada:** identificar los posibles puntos de inicio de una aplicación.
- **Análisis de acoplamiento:** señalar módulos con muchas relaciones o dependencias difíciles de mantener.
- **Informe de arquitectura:** generar un resumen legible de la estructura y las dependencias del proyecto.

Estas funciones son objetivos futuros, no funcionalidades implementadas.

### Tecnologías previstas

- **Rust** para analizar código y extraer dependencias.
- **TypeScript** para la interfaz de visualización.

Las decisiones técnicas pueden cambiar durante el desarrollo.

### Estado

**Planificación inicial.** Actualmente, este repositorio contiene únicamente documentación y una licencia. Todavía no incluye código ejecutable.

### Hoja de ruta inicial

1. Elegir los primeros lenguajes y formatos de proyecto compatibles.
2. Diseñar un modelo de datos para archivos, módulos y dependencias.
3. Crear un analizador inicial de la estructura del repositorio.
4. Mostrar las dependencias en una interfaz navegable.
5. Añadir métricas de acoplamiento e informes de arquitectura.
